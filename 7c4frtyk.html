Admin

Sign in with your Google account to edit the CV.

One-time setup needed:
  1. Open Google Cloud Console → Credentials
  2. Create an OAuth client ID → type Web application
  3. Add the site URLs under Authorized JavaScript origins (e.g. http://127.0.0.1:8642 and your https://…github.io address)
  4. Copy the client ID and paste it into admin.js → GOOGLE_CLIENT_ID

⚠ You opened this page from a file:// location. Serve it over http(s) (local server or GitHub Pages) — Google Sign-In and the live preview need it.
